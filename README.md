# MODERN HOUSE | Website Redesign

모던하우스의 라이프스타일 브랜드 이미지를 바탕으로 제작한 웹사이트 리디자인 프로젝트입니다.

기존 쇼핑몰 웹사이트의 구조와 인터랙션을 활용하고, 모던하우스의 다양한 리빙 제품과 감성적인 비주얼을 적용해 새로운 쇼핑 경험을 구현했습니다.

## Design Concept

**Everyday Living, Better Moments.**

일상 속 공간을 더욱 특별하게 만드는 모던하우스의 브랜드 콘셉트를 바탕으로, 편안하고 감각적인 라이프스타일 쇼핑몰을 표현했습니다.

따뜻한 뉴트럴 컬러와 다채로운 제품 이미지를 활용하고, 여백과 타이포그래피를 정돈해 상품 콘텐츠에 집중할 수 있도록 디자인했습니다.

## Main Features

### 01. Hero Visual

- 4개의 라이프스타일 비주얼 슬라이드
- 자동 재생 및 슬라이드 전환
- 페이지네이션 및 재생·일시정지 기능

### 02. Category Collection

- 주방, 침구, 리빙, 수납 카테고리 소개
- 가로형 상품 카드 슬라이더
- 카드 호버 및 버튼 인터랙션

### 03. Weekly Special

- 할인 상품을 소개하는 프로모션 섹션
- 실시간 카운트다운 타이머
- 상품 슬라이더 및 가격 정보

### 04. Best Ranking

- 인기 상품 01~16위 랭킹
- 8개 상품씩 2개의 슬라이드 구성
- 좌우 화살표를 이용한 상품 탐색

### 05. Footer

- 브랜드 및 회사 정보
- 주요 안내 링크
- 페이지 최상단 이동 버튼

## Tech Stack

- **HTML5:** 시맨틱 마크업 및 콘텐츠 구조
- **CSS3:** 레이아웃, 반응형 스타일, 애니메이션
- **JavaScript:** 슬라이더 제어 및 사용자 인터랙션
- **Swiper.js:** 배너 및 상품 슬라이드
- **Figma:** UI 디자인 및 레이아웃 설계

## Project Notes

기존 웹사이트의 HTML/CSS/JavaScript 구조와 인터랙션을 분석하고 재사용하여 디자인 변경과 퍼블리싱 작업을 진행했습니다.

불필요한 기능 재구현을 줄이고, 기존 동작을 유지하면서 브랜드에 맞는 비주얼과 콘텐츠를 적용하는 데 중점을 두었습니다.
